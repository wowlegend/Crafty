## Goal frame

**Goal.** A visitor to the public repo meets the game (README, the app, its CI, a short doc set), not closed process
records, and every retired record stays one command away.

**Metric.**
1. The annotated tag `records/2026-10-29` points at main's commit before the removal and is on GitHub.
2. Every removed path is named by no doc-currency canonical doc, rule file, `CLAUDE.md`, gate, script, test, CI step,
   lane plan dated 2026-10-27 or later, live page or the Kevin inbox, except four named only as history (DECISIONS item
   100); doc-currency, the unit suite and the build stay green; `git show records/2026-10-29:<path>` prints each one.
3. `memory/CHANGELOG.md` is generated by `frontend/scripts/ci/changelog.mjs`; `--check`, a manual command (item 101
   as amended after the review), goes red on a stale or hand-edited file and on a line naming a commit outside the
   history, and stays green on a current one (an identity mutant stays green); `--write` refuses mid-merge.

**Anti-attack (GF-L2).**
- Deleting by directory or by age deletes what a live doc cites. So every candidate is grepped by its file name
  (bounded, so `KEVIN-REVIEW` does not match `KEVIN-REVIEW-BATCH`) over every tracked file, and the list is computed,
  not chosen.
- A record that only a removed record cites is still removable; a record cited only by a stale pointer the command
  session has already retired (ACTIVE_PLAN T15 retires `sota-2026-09/OVERNIGHT.md`) is named as such.
- A "generated" CHANGELOG that is written once and never checked is hand-written by another name. So the test drives
  the check on a throwaway git history where the answer is known. (Run beside doc-currency in the commit tier and CI
  at first; the review showed that a lane's merge commit and the PR and push CI checkouts see different histories, so
  the check left every tier.)
- Main's first-parent chain here is not a list of landings: a lane lands by fast-forward after merging main in, so
  main's first parents run through the last lane's own commits. The landings are what git can prove (the main tips
  that lanes merged in, and the June merges into main) plus the merged pull requests, whose titles only GitHub holds.
